# Security

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and choose
**Report a vulnerability**
([direct link](https://github.com/takwerx/tak-server-installer/security/advisories/new)).
Do not open a public issue, and do not post details, logs or proof-of-concept
data where others can read them.

## Supported versions

Only the latest version on the `main` branch gets security fixes. Pull it before reporting.

## What to expect

We acknowledge a report within 3 working days, tell you whether we can
reproduce it, and keep you updated until a fix ships. Confirmed issues are
fixed in a new release and credited to you if you want.

## Scope

The install, SSL/Caddy and hardening scripts and the Docker workflow in this repository: what they open, what they write and with what permissions, and what they download. Vulnerabilities in TAK Server itself belong with the TAK Product Center at tak.gov.
